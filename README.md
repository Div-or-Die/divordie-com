# divordie.com

Company site for Div or Die LLC. Static HTML, deployed via GitHub Pages.

## Structure

- `index.html` — home
- `about/` — company
- `contact/` — contact page
- `privacy/` — privacy policy (App Store Privacy Policy URL)
- `CNAME` — custom domain for GitHub Pages

## Deploy

Push to `main`. GitHub Pages serves from the repo root.
